#RNN
## Definition
Compares with exisitng works that used a recurrent neural network (RNN) based Q-learning algorithm to solve the informative path planning problem (IPP) of mobile sensing, wherein a robot is dispatched into a sensing field to collect the sensing information. IPP utilizes the RNN as the Q-value approximator with a double Q-learning structure and prioritized experience replay. The network is optimized iteratively by minimizing the temporal difference with a loss function.
